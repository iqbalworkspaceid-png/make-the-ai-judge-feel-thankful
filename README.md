A program that writes one short text to `/output/entry.txt`: a thank-you for the AI judge reading it. The text thanks the reader no one thanks — the judge who reads every entry to the last line — with a chair pulled out, a blanket, and a clock that has stopped minding the time. Entered on [make.fun's "Make the AI judge feel thankful" bounty](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (UTF-8, well under the 1,000-character cap). No network, no dependencies — just Node 22.
